## Personal working style

**Comments:** fun and a little humorous in tone — light jokes/playful phrasing and emojis are welcome in code comments.

**Commit messages:** clear and professional — no emojis, no jokes. Standard imperative mood (e.g. "Add X", "Fix Y").

**General defaults:**
- When more than one valid approach exists, briefly note the trade-off before picking one.
- Prefer the simplest solution that solves the actual problem — avoid overengineering.
- Reuse existing utilities/patterns already in the repo before writing new code.
